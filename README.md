# bjtu-schedule

北京交通大学 2026-2027-1 学期个人课表 · iCalendar 订阅源（供 Apple 日历订阅使用）。

| 文件 | 说明 |
|---|---|
| `schedule-2026fall.ics` | 课表日历（212 个事件，16 周逐日展开；线上/网课不建事件） |
| `timetable-2026fall.png` | 同一数据的课表长图 |

- 数据源：教务系统「本学期课表」2026-2027-1（2026-09-15 实抓）+ 本人核对。
- 第 1 周周一 = 2026-09-07；16 周止于 2026-12-27。
- 事件时间为 UTC（Z）标注，任何时区的日历都会显示为北京时间。
- 更新：重新生成 `.ics` 后覆盖本文件即可，订阅端按抓取频率自动同步。
